# The log directory mirrors Claude Code's projects folder, beside goodall's own bookkeeping

An eval's log directory keeps raw records in their source's own layout and goodall's bookkeeping in folders of its own, never mixed. `transcripts/` mirrors Claude Code's `projects` folder: for each Claude session, `<project folder>/<session id>.jsonl` and the whole `<session id>/` folder beside it (subagent transcripts, tool results, images and whatever a later Claude Code version adds), byte for byte at the same paths, and nothing is ever deleted from it. `superseded-transcripts/<moment>/` holds, at the same relative paths, any earlier copy that a rewritten source no longer starts with; it is raw too, kept outside `transcripts/` so that an importer never reads it as a second Claude session with the same id. The rest is goodall's own working state, for goodall to read and no importer to touch: `transcript-sync/` (failure notes for `goodall status`, locks, and the Claude projects folders that hooks have copied from) and `work-blocks/` (the active work block's marker, its heartbeats, and ended records waiting to be written to the record repo). We chose to mirror Claude Code's layout, internal and unversioned as it is, over a layout of goodall's own design, such as one folder per work block, because Inspect Scout's importer and any other tool that reads a Claude projects folder can then be pointed at `transcripts/` unchanged, and because a copy at its original's path can always be checked against it. The price is that goodall's files must never go inside `transcripts/`, and that the mirror's shape changes whenever Claude Code's does.
