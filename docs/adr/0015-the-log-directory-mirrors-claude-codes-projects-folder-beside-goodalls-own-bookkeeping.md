# The log directory mirrors Claude Code's projects folder, beside goodall's own bookkeeping

An eval's log directory keeps raw records in their source's own layout and goodall's bookkeeping in folders of its own, never mixed. `transcripts/` mirrors Claude Code's `projects` folder: for each Claude session that has a record inside a work block (ADR 0019), `<project folder>/<session id>.jsonl` and the whole `<session id>/` folder beside it (subagent transcripts, tool results, images and whatever a later Claude Code version adds), and each project's `MEMORY.md` and `memory/`, byte for byte at the same paths, and nothing is ever deleted from it. `claude-config/` holds what goodall copies from the rest of Claude Code's config folder, which is only what a short allow-list names, the prompt history `history.jsonl` and each Claude session's file-edit backups `file-history/<session id>/`, never settings, credentials or anything else there; inside it, each config folder gets a folder named after its path, as Claude Code names a project folder, laid out as the config folder is, so two config folders' prompt histories never meet and no `*.jsonl` sits where an importer pointed at the log directory would take it for a Claude session. `superseded-transcripts/<moment>/` and `superseded-claude-config/<moment>/` hold, at the same relative paths, any earlier copy that a rewritten source no longer starts with; they are raw too, kept apart so that an importer never reads one as a second Claude session with the same id. The rest is goodall's own working state, for goodall to read and no importer to touch: `transcript-sync/` (the ended work blocks whose agent sessions are still to be copied, locks, and the Claude config folders that hooks have run in) and `work-blocks/` (the active work block's marker, its heartbeats, and ended records waiting to be written to the record repo). We chose to mirror Claude Code's layout, internal and unversioned as it is, over a layout of goodall's own design, such as one folder per work block, because Inspect Scout's importer and any other tool that reads a Claude projects folder can then be pointed at `transcripts/` unchanged, and because a copy at its original's path can always be checked against it. The price is that goodall's files must never go inside `transcripts/`, that the mirror's shape changes whenever Claude Code's does, and that copying anything new from the config folder, which also holds secrets, takes a decision to widen the allow-list.
