# Three record layers, with raw records kept verbatim

An eval's data is kept in three layers: raw records copied byte for byte in their original layout (Claude Code transcripts, telemetry), goodall's own records written as readable files in the record repo, and derived data (actor labels, an Inspect Scout database) that can always be regenerated from the first two. Raw transcripts stay in Claude Code's own folder layout, even though that format is internal and changes between versions, because Inspect Scout's importer reads that layout directly and because a transformed copy could never be checked against the original. Goodall's own records are Markdown and JSON with field values borrowed from Inspect's event types, chosen over storing Inspect or OpenTelemetry objects directly because people read and diff these files, and so that Inspect and Scout stay an optional install used only when exporting.
